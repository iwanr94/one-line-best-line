## The line

> My smart fridge emailed me about my midnight snacking, and I have never been judged so politely by an appliance.

One sentence, 112 characters, with the turn at the end: judged — politely — by an appliance.

## How it works

`main.py` (Python stdlib only, no network) writes that single line to `/output/entry.txt`. It asserts the line is one non-blank line of 1–240 characters before writing.

Run it like the grader:

```sh
python3 -P -s main.py
```
